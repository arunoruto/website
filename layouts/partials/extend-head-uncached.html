{{/* Page-aware head additions (Blowfish calls this partial uncached, with the page as context, right after its own head content). Interactive figures: widget bundles built by layouts/shortcodes/viz.html keep `import … from "three"` external, and this import map points the bare specifier at the vendored copy in assets/lib/three/. That way N widgets on a page share one three.js download (and one module instance) instead of each bundling its own ~750 KB. three.module.min.js loads ./three.core.min.js by relative path, so that import is rewritten to the fingerprinted core URL before the module itself is fingerprinted - both stay cache-safe across upgrades. See assets/lib/three/VERSION. */}} {{- if .HasShortcode "viz" -}} {{- $alg := site.Params.fingerprintAlgorithm | default "sha512" -}} {{- $core := resources.Get "lib/three/three.core.min.js" | resources.Fingerprint $alg -}} {{- $moduleRaw := resources.Get "lib/three/three.module.min.js" -}} {{- $module := resources.FromString "lib/three/three.module.min.js" (replace $moduleRaw.Content "./three.core.min.js" $core.RelPermalink) | resources.Fingerprint $alg -}} {{- $importmap := dict "imports" (dict "three" $module.RelPermalink) "integrity" (dict $module.RelPermalink $module.Data.Integrity $core.RelPermalink $core.Data.Integrity) -}} {{- end -}} {{/* KaTeX auto-render fallback. Blowfish v3 appends js/katex-render.js to js/main.bundle.js only when the page has {{< katex >}}, but resources.Concat caches by target path alone, so whichever page happens to build first decides the bundle for every page - and math silently stays raw on the others. This re-runs the same call the theme intends; running it twice is harmless. */}} {{- if .HasShortcode "katex" -}} {{- end -}} {{/* wideLayout: true (front matter) loosens Blowfish's prose column for pages that are mostly figures — wider body, less side padding, ~90ch text — while leaving every other page untouched. Only kicks in at lg and above; phones and tablets keep the theme's layout. The wide-figure gutter pull shrinks to match the smaller padding. */}} {{- if .Params.wideLayout -}} {{- end -}}
